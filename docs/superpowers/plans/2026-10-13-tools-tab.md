# Tab "Công cụ" — Kế hoạch triển khai

> Spec: `docs/superpowers/specs/2026-10-13-tools-tab-design.md`

**Mục tiêu:** Mục "Công cụ" trên sidebar → lưới card công cụ (ghim được, ghim hiện thành submenu) cùng 5 công cụ: Bấm giờ/Đếm ngược, Tính ngày, Bốc thăm/Chia nhóm, Đếm chữ, Xử lý dòng.

**Kiến trúc:** Logic thuần trong `src/lib/tools/*` (test bằng vitest), UI trong `src/components/tools/*`, ghim lưu localStorage qua `usePinnedTools`. `dashboard.tsx` giữ `activeTool` cạnh `activeSection`.

**Tech:** Next 16 (client components), React 19, antd 6, dayjs, Tailwind 4 + CSS token trong `globals.css`, vitest.
